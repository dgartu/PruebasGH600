## ✨ Características

- ⚡ **Rápido y ligero** — Express 5.x en acción
- 🩺 **Health check integrado** — monitorea el estado del servicio
- 🎯 **Listo para producción** — arquitectura limpia y extensible

---

## 📋 Requisitos

| Herramienta  | Versión mínima |
|--------------|----------------|
| Node.js      | 18.x o superior |
| npm          | 8.x o superior  |

---

## 🛠️ Instalación

```bash
npm install
```

---

## 🏃‍♂️ Uso

```bash
npm start
```

> El servidor se iniciará en **`http://localhost:3000`** 🚀

---

## 📡 API Endpoints

| Método | Ruta        | Descripción                              | Ejemplo de respuesta                     |
|--------|-------------|------------------------------------------|------------------------------------------|
| `GET`  | `/`         | Mensaje de bienvenida                    | `¡Hola desde Express!`                   |
| `GET`  | `/health`   | Estado del servicio (JSON)               | `{"status":"ok"}`                        |

---

## 🧪 Pruebas

```bash
curl http://localhost:3000/
curl http://localhost:3000/health
```
